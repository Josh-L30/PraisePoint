# Design and verification history

These records capture what was explored and checked at each stage. Earlier screenshots, approval states, local preview links and statements such as "not deployed" describe that stage; they do not describe the current release. Local preview URLs may no longer work.

The latest release in this archive is [S35: direct login and sidebar toggle](S35-direct-login-sidebar-release.md). Login opens immediately on desktop, tablet and mobile, with no entrance video. The current sidebar retains its original panel symbol with a larger, evenly spaced hover/focus arrow.

S18–S25 record login alternatives leading to Evening Calm on desktop/tablet and Open Horizon on mobile. S27–S29 record mobile entrance experiments and sidebar refinements; the owner later cancelled the video work. These experimental screenshots are historical references, not features to reintroduce.

Temporary players, generated video variants and browser/test output remain outside version control under the existing ignore rules. Application source, tests and these selected evidence artifacts are versioned. Supabase records and original media use the separate backup workflow.
