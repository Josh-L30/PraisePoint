# S01: Google sign-in and personal workspace

Status: Done for the S01 foundation. The full presentation website is still in development.
Goal: a volunteer signs in with Google and reaches a private workspace through the approved glass interface.

Scope: Google PKCE/session recovery, profile/workspace initialization, responsive shell, collapsing desktop navigation, mobile drawer, preferences, and truthful empty/loading/error states. Church invitations, editing, media, offline services, and deployment belong to later sprints.

## Acceptance and evidence

- [x] A01: live Google login creates one profile and personal workspace; reload and repeat login reuse the same workspace. Real Google Cancel returns to recovery and then sign-in.
- [x] A01 recovery: disabled provider, failed network check, denied callback, and expired server identity recover. Expiry/network browser cases use controlled API fixtures; they are UI evidence, not live OAuth evidence.
- [x] A02 groundwork: hosted transaction assertions verify two-user isolation, ownership/role write denial, trusted provider checks, and idempotence. Live anonymous API checks passed. Shared church access is S02.
- [x] A10 foundation: collapsing desktop navigation, phone-width reflow, mobile keyboard focus entry/wrapping/Escape/return, and reduced transparency. Motion has a reduced-motion CSS fallback. Physical device/room validation remains S10.
- [x] Sign-out clears the current local session and device marker; protected navigation returns to login. Real media cleanup is added and retested in S08.
- [x] No artificial loading delay, fake signed-in state, or elevated frontend credential.

## Configuration and limits

Google is the only enabled provider. All three exact local callbacks and the development Site URL persisted. Google basic scopes and owner test user persisted; the Google application remains in testing. Credential stays only in Supabase. No billing or publication.

The earlier runner blocker was investigated: Playwright Chromium was missing, then Windows reported about 640 MiB free of 8 GiB. The approved official browser download completed. Temporary agent-created preview/setup tabs were closed, and tests now use one worker. The production preview was started separately; all six browser checks passed. No unidentified Node process was terminated.

Docker/CLI pgTAP is unavailable; hosted rollback assertions are the documented replacement, not a claim that npm run test:db passed. Main bundle remains about 638 kB / 185 kB gzip and needs feature splitting before release. Real physical phone/projector, video, and offline rehearsal remain later acceptance work. The app is not deployed.
